# 🌡️ Temperature Converter

A modern, minimalist temperature converter built with HTML, CSS, and JavaScript. Convert temperatures between Celsius, Fahrenheit, and Kelvin with a clean interface and instant results.

## ✨ Features

- 🌡️ Convert between Celsius, Fahrenheit, and Kelvin
- ⚡ Real-time temperature conversion
- 🎨 Modern, minimalist user interface
- 📱 Responsive design for desktop and mobile
- 🔄 Reset button to clear all values
- 🎯 Custom SVG favicon
- ♿ Accessible input labels and keyboard-friendly controls

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Styling, responsive layout, and animations
- **JavaScript** — Temperature conversion logic
- **Google Fonts** — DM Sans and Manrope typography

## 🌡️ Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius to Fahrenheit | °F = (°C × 9/5) + 32 |
| Celsius to Kelvin | K = °C + 273.15 |
| Fahrenheit to Celsius | °C = (°F − 32) × 5/9 |
| Kelvin to Celsius | °C = K − 273.15 |
